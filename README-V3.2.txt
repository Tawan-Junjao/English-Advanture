English Adventure V3.2

แก้ระบบสะกด:
- ไม่ส่งตัวอักษรเดี่ยว เช่น C ให้ระบบอ่านโดยตรงอีก
- ใช้ชื่อเสียงที่แน่นอนแทน เช่น C=see, A=ay, T=tee
- ป้องกันเสียง “capital C”, “uppercase A” หรือคำอธิบายอื่นจากระบบ
- อ่านทีละตัวและรอจนเสียงตัวก่อนหน้าจบจริง
- ปุ่มอ่านคำเต็มและปุ่มสะกดแยกจากกัน

ตัวอย่าง:
CAT จะได้ยินเฉพาะ “see ... ay ... tee”
