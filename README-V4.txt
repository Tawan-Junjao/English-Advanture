English Adventure V4 — Bundled Audio Edition

จุดสำคัญของ V4
- ตัวอักษร A–Z ใช้ไฟล์ MP3 ที่อยู่ในเกม
- คำศัพท์ทั้งหมด 54 คำใช้ไฟล์ MP3 ที่อยู่ในเกม
- ไม่พึ่ง SpeechSynthesis ของ Safari, Chrome หรือระบบปฏิบัติการ
- เสียง A, I, L และตัวอื่นจะเหมือนกันทุกอุปกรณ์
- โหมด Spelling แสดงเฉพาะรูป ช่องว่าง และปุ่มตัวอักษร
- ปุ่ม “อ่านคำ” กับ “สะกดคำ” แยกการทำงานชัดเจน
- Service Worker เก็บไฟล์เสียงไว้เพื่อเล่นออฟไลน์หลังโหลดครบครั้งแรก

หมายเหตุเรื่องเสียง
ไฟล์เสียงในชุดนี้เป็นเสียงสังเคราะห์ที่สร้างและฝังไว้ล่วงหน้า จึงคงที่ทุกเครื่อง
ไม่ใช่เสียงบันทึกจากครูเจ้าของภาษาจริง แต่แก้ปัญหา Browser อ่าน A เป็น I
หรือเติมคำว่า capital ได้

วิธีอัปโหลด GitHub Pages
1. แตก English_Adventure_V4_GitHub.zip
2. ลบไฟล์เก่าใน Repository หรืออัปโหลดไฟล์ใหม่ทับทั้งหมด
3. ต้องเห็น index.html, app.js, style.css, sw.js และโฟลเดอร์ assets ที่หน้า root
4. Commit changes
5. รอ Actions / Pages deployment เป็นสีเขียว
6. ทดสอบด้วย Incognito ก่อน
7. ถ้าไอคอนบนหน้าจอโฮมยังเป็น V3 ให้ลบไอคอนเดิม แล้วเพิ่มเว็บไซต์ใหม่
