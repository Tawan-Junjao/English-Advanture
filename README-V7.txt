English Adventure V7 — Piper Neural Voice

รุ่นนี้ไม่ต้อง:
- สมัคร Azure
- ใส่ API Key
- อัดเสียงเอง

V7 ใช้ Piper Neural TTS และโมเดล en_US-joe-medium
สร้างเสียงไว้ในไฟล์เกมครั้งเดียว แล้วเล่นแบบออฟไลน์ได้

วิธีใช้งานบน Windows
1. แตก ZIP
2. ดับเบิลคลิก “ติดตั้ง_ffmpeg_ครั้งแรก.bat” หนึ่งครั้ง
3. ปิดแล้วเปิด Command Prompt ใหม่ หรือรีสตาร์ตเครื่อง
4. ดับเบิลคลิก “กดครั้งเดียว_สร้างเสียง_V7.bat”
5. รอระบบดาวน์โหลด Piper/โมเดลและสร้างเสียงทั้งหมด
6. ฟัง:
   - letters_a.mp3 = A / ay
   - letters_i.mp3 = I / eye
   - letters_l.mp3 = L / ell
7. เมื่อพอใจ ให้อัปโหลดไฟล์เกมทั้งหมดขึ้น GitHub

ข้อสำคัญ
- A และ I ใช้ข้อความคนละคำอย่างชัดเจน:
  A = ay
  I = eye
- ไม่ใช้ Browser SpeechSynthesis
- ไม่ใช้ eSpeak สร้างเสียงสุดท้าย
- ไฟล์เสียงที่สร้างจะเขียนทับเสียงเดิมในเกม

สิทธิ์ใช้งาน
