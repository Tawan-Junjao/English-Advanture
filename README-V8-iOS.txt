English Adventure V8 — iPhone/iPad Edition

จุดสำคัญ
- ใช้ SpeechSynthesis ของ Apple ที่มีอยู่ใน iPhone/iPad
- มีหน้าตั้งค่าเสียง ให้ทดลอง A, I และ L ก่อนเล่น
- เลือกเสียง เช่น Samantha, Ava, Allison, Susan หรือเสียงอังกฤษอื่นที่เครื่องมี
- ปรับความเร็วเสียงได้
- ตัวอักษรใช้ข้อความกำหนดชัดเจน:
  A = ay
  I = eye
  L = ell
- โหมดสะกดอ่านทีละตัวและเว้นช่วง
- ไม่ต้องใช้ Azure, Piper, API key หรืออัดเสียงเอง

วิธีใช้
1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages
2. เปิดด้วย Safari บน iPhone/iPad
3. เข้าเมนู “ตั้งค่าเสียง Apple”
4. ทดลองเสียง A, I, L
5. เลือกเสียงที่ฟังชัดที่สุด แล้วกดบันทึก
6. เริ่มเล่นเกม

ข้อจำกัด
เสียงที่มีให้เลือกขึ้นกับรุ่น iOS และเสียงที่ติดตั้งในเครื่อง
ถ้าเสียงมีน้อย ให้เข้า Settings > Accessibility > Spoken Content > Voices > English
แล้วดาวน์โหลดเสียงคุณภาพสูงเพิ่มเติม
